# Awaken - flight computer messages (shown in the message line of the flight panel)
# UTF-8.  Notation: see assets/README.md (section "Text notation").  In short: "ID | text", "\n" = new line in the game,
# {stop}/{tab1..5}/{nbsp}/{sp}/{xNN} = control bytes, continuation lines start with "    |", lines starting with # are comments.
# The IDs and the [LABEL] names are used by the code: do not rename or renumber.

[_SYSTEMREADY]
# Flight computer message _SYSTEMREADY: All systems ready.
# Printed in the message line of the flight panel (panel font FONT.f); the message is
# terminated by \n (new line) and the engine byte #0A.  Line width about 28 characters of the panel font.  Lines: one per \n.
0 | Все системы готовы.\n
    |
